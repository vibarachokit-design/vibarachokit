Falta un paso en Supabase (5 minutos, una sola vez)

Para guardar apps, reseñas y precios digitales, la base de datos necesita unas tablas nuevas. Se crean pegando un código que ya está listo:

  1. Presiona Copiar código.
  2. Presiona Abrir el editor de Supabase e inicia sesión si te lo pide. Se abre una consulta nueva en blanco (si no, en el menú izquierdo entra a SQL Editor y elige New query).
  3. Pega el código (Ctrl + V o ⌘ + V) y presiona el botón verde Run.
  4. Cuando diga Success, vuelve aquí y presiona Ya lo hice.
